## 🚀 Ordre de Déploiement Recommandé

### Phase 1: Installation (1ère fois)
```
1. S'assurer que WSL2 est activé sur Windows
2. Exécuter: DEPLOY_STORAGE.bat
3. Attendre la fin de l'installation
4. Tester: CHECK_HEALTH.bat
```

### Phase 2: Validation
```
1. Vérifier la connexion: wsl psql -d opticut_pro
2. Créer un backup test: BACKUP_ADVANCED.bat
3. Consulter les logs: wsl tail -50 /var/log/postgresql/*
```

### Phase 3: Configuration Production
```
1. Programmer les backups quotidiens (Task Scheduler)
2. Configurer le monitoring (Prometheus/Grafana)
3. Mettre en place les alertes d'espace disque
4. Documenter les procédures opérationnelles
```

```
C:\OptiCut_Data\
├── postgres\data\           ← Base PostgreSQL

C:\OptiCut_Backup\
├── full_backup_*.sql        ← Backups complets

```

/var/log/postgresql/                    ← Logs d'erreurs
```

```
C:\OptiCut_Logs\maintenance.log         ← Logs de maintenance

## 📞 Support & Troubleshooting

### Problème Courant
```
PostgreSQL ne démarre pas
↓
wsl sudo service postgresql status
↓
Vérifier les logs: wsl tail -50 /var/log/postgresql/*.log
↓
Redémarrer: wsl sudo service postgresql restart
```

### Urgent: Perte de Données
```
1. Arrêter l'application immédiatement
2. Exécuter: .\RECOVERY_EMERGENCY.bat
3. Choisir le backup approprié
4. Vérifier l'intégrité: CHECK_HEALTH.bat
```
