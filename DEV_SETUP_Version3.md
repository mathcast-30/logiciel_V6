# Installation et configuration pour le développement

Ce document décrit pas-à-pas comment préparer un poste Windows pour développer et exécuter OptiCut Pro V4 (dossier `logiciel_V6`).

Prérequis (Windows)
- Git
- Node.js (LTS) et npm
- Miniconda / Anaconda
- Visual Studio Build Tools (pour compiler l'extension C++)

1) Cloner le dépôt

```bash
git clone https://github.com/mathcast-30/logiciel_V6.git
cd logiciel_V6
